Pilih jenis event kamu untuk mengisi konfigurasi nama, tema, dan durasi pose secara otomatis:

1. Identitas Acara & Sekolah

Akan ditampilkan di layar sambutan Kiosk, header unduhan smartphone, dan Live Projector Wall.

2. Perilaku Kiosk & Kamera

Digunakan operator untuk keluar dari layar Kiosk.
Jika dicentang, layar Kiosk akan meminta pengunjung memasukkan kode tiket/voucher yang valid (dikelola di menu Manajemen Tiket) sebelum sesi kamera dapat dimulai.

3. Mode Pembayaran Mandiri / Vending Machine (QRIS)

Pengunjung akan diminta memilih paket foto dan melakukan pembayaran QRIS di layar Kiosk sebelum kamera terbuka.
Kosongkan untuk menggunakan QRIS simulator dinamis bawaan.

4. Integrasi Hardware Printer Foto

Jika dinonaktifkan, Kiosk akan beralih ke Eco-Digital Mode (hanya menyediakan QR code untuk unduhan softfile ke smartphone).
Foto langsung dikirim ke printer seketika proses render selesai.
Contoh: Canon SELPHY CP1300 atau EPSON L3210 Series
